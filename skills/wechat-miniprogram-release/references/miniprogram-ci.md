# miniprogram-ci 密钥上传

仅当用户明确要求以密钥及 IP 白名单方式发布时使用；不需要微信开发者工具登录。官方文档：https://developers.weixin.qq.com/miniprogram/dev/devtools/ci.html

## 准备和人工操作

1. 核实目标 AppID、实际运行上传的机器及公网出口；VPN、代理和 CI 环境可能改变出口。由有权限的用户在微信公众平台对应小程序的「管理 → 开发管理 → 开发设置 → 小程序代码上传」中取得代码上传私钥，并为该 AppID 配置实际出口 IP 白名单；界面名称以平台当前版本为准。由用户自行完成登录、管理员扫码确认、密钥下载和白名单修改。需要用户提供可读取的本机私钥文件路径，不要求粘贴密钥内容。检查文件可读、目标 AppID 与项目相符；白名单是否生效以用户确认及实际上传结果为准，不能仅凭本地 IP 猜测成功。
2. 私钥仅保存在用户控制且权限受限的仓库外位置；不写入仓库、技能、构建产物、命令输出、聊天或日志。仅将私钥路径传给工具，不打印内容；用户负责管理和轮换私钥。
3. 检测 `node`、`npm` 及现有 `miniprogram-ci`。建议在与项目依赖分离的 Node 环境中全局单独安装 `npm install -g miniprogram-ci`；先检查该版本的 Node 引擎要求、全局安装位置和现有版本，避免覆盖用户正在使用的工具。安装失败时报告原因；不要修改项目依赖或锁文件。项目历史构建 Node 与 CI 上传工具可能要求不同版本，可分开执行。

## 上传

- 核实 `miniprogram-ci --help` 和 `miniprogram-ci upload --help` 支持的参数，以官方文档及实际版本为准。CLI 参数对应项目路径、私钥路径、AppID、版本及备注；示例：

  `miniprogram-ci upload --pp <产物绝对路径> --pkp <私钥文件绝对路径> --appid <目标AppID> --uv <版本号>`

- 使用实际构建产物和明确的版本；备注参数先通过当前版本帮助确认，若 CLI 不支持则采用官方 Node API 的 desc。处理路径中的空格，执行前验证参数而不输出私钥内容。按官方当前文档及实际工具版本确认编译选项，避免改变产物含义。检查退出状态和明确上传结果；失败时结合报错检查私钥、AppID、项目权限、出口 IP、代理与白名单，不自动重新生成密钥或更改后台配置。
