# 微信开发者工具连接与上传

默认采用此方式。微信开发者工具的 CLI 随开发者工具安装，和 npm 的 `miniprogram-ci` 是不同工具；无需为了使用开发者工具 CLI 全局安装 npm 包。官方文档：https://developers.weixin.qq.com/miniprogram/dev/devtools/cli.html

## 准备和人工操作

1. 检查本机是否已安装可用的微信开发者工具、版本及 CLI；Windows 为安装目录下的 `cli.bat`，macOS 为 `<安装路径>/Contents/MacOS/cli`。优先使用本机现有安装；缺失时指导用户从微信官方渠道安装并完成首次启动。不要假定安装目录、权限或某个 MCP 一定存在。
2. 提示用户在开发者工具的「设置 → 安全设置」开启「服务端口」。若使用本机可用的 MCP 接口，按当前版本界面开启相应 MCP 服务、连接授权并核实工具确实可用；MCP 的名称、端口、token 和配置位置以实际版本为准，不猜测。仅在所选连接方式需要时设置；token 不写入技能、仓库或日志。
3. 检查登录状态和目标项目权限。需要扫码登录、在微信侧确认、加入项目成员或授权时，明确告知用户操作并等待；不要代替用户确认或绕过权限。如果弹出连接或上传确认，等待用户操作。确认所登录账号对目标 AppID 有上传权限。

## 上传

- 有可用且经过授权的开发者工具 MCP 时，优先使用其实际提供的项目导入、上传能力；按接口实际参数将目标产物目录导入，以该目录上传。返回任务 ID 时轮询最终结果。
- MCP 不可用时，采用官方随工具提供的 CLI；用实际 CLI 的 `upload -h` 核对版本支持的参数。Windows 示例（把占位值替换为已核实的绝对路径、版本和备注）：

  `& '开发者工具安装目录\cli.bat' upload --project '产物绝对路径' --version '1.0.0' --desc '环境名称'`

  官方要求工具已登录且开启服务端口。检查退出码及明确结果，必要时使用工具支持的结果输出核对，不把命令启动、用户取消或未知状态当作成功。CLI 和 MCP 均不可用时，报告实际阻塞及需用户完成的步骤，不冒称上传。
