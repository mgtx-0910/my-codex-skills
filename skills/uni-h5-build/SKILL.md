# uni-app H5 打包

本技能只负责生成和检查 H5 产物。先读取当前配置的 [项目打包规则](profiles/default/SKILL.md)，按用户指定的项目和目标环境执行；替换项目规则时，应提供项目定位方式、环境与配置来源、构建工具和命令、输出目录及必要校验，不假定子技能自动独立加载。用户要求其他项目时，先核实对应规则，不能直接套用现有项目的配置。

1. 确认项目、目标环境、代码来源、未提交改动和输出位置。环境不明确或无法映射到现有配置时询问用户；不得依据旧配置猜测。用户指定分支时以明确要求为准；未指定分支时确认实际代码来源，不擅自切换分支或合并。记录源提交 SHA 与构建所需的未提交改动；保护工作区和现有产物。
2. 按项目规则在隔离构建工作区准备依赖、环境配置和构建工具。切换环境时仅调整本次构建需要的配置，保护用户已有修改；若不能安全隔离，先确认如何处理。核对运行时接口地址、路由模式及资源基础路径，不自行添加或更改服务器配置。历史产物不能作为本次构建结果。
3. 默认使用命令行进行 H5 生产构建，无需打开图形界面。优先使用项目已有且验证可用的构建脚本或独立 uni-app CLI；也可按项目规则使用本机已安装的 HBuilderX 编译器直接从命令行构建。先核实实际工具、版本、依赖及参数，不臆造 npm 脚本或将开发模式当成生产构建。命令行方案不可用时先排查并说明阻碍，不自行改用图形界面；如确需安装、登录或用户操作，说明具体情况。
4. 核对进程或工具的最终结果和完整日志，明确没有构建错误，并确认本次产物目录及入口、静态资源属于刚完成的构建。校验实际环境配置；条件允许时进行本地页面和引用资源的冒烟检查，受路由、接口或登录条件限制时如实说明。不能用旧文件、目录修改时间或仅凭退出码证明成功。
5. 报告项目、目标环境、实际生效的接口地址、代码来源和 SHA、构建中使用的配置变更、工具及结果、产物绝对路径、验证范围与限制。除非用户明确要求另行执行，不上传、部署、发布或修改远程环境。
