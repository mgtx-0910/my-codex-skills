# 分支会话标题

## 按当前工具选择方式

此技能的命名规则与宿主无关，但会话标题工具、事件钩子和配置格式因宿主不同而不同。先确认**当前会话实际所在的工具**以及当前可用的改名能力，不要仅凭机器上存在某个目录判断宿主。

- Codex：用户明确要求启用或安装自动标题时，按 `references/install.md` 安装或检查 Codex 专用钩子。只因普通任务触发此技能时不要擅自安装。
- OpenCode：如果当前环境实际提供会话改名工具，按照下方规则调用；其自动化安装适配尚未提供，不要运行 Codex 安装脚本。
- Claude Code：如果当前环境没有模型可调用的改名工具，可为用户提供最终标题和 `/rename <标题>`，由用户在当前会话执行；不要声称已经自动改名。
- 其他工具：优先使用当前宿主提供的会话改名能力；没有可调用接口时提供建议标题并说明需要手动设置。不要假设支持 Codex 的钩子或状态文件。

具体能力和安装状态见 `references/platforms.md`。仅加载技能不会自动注册钩子；自动更新需要该宿主对应的、经过验证的集成。尊重宿主的授权与用户的手动改名。

## 固定前缀

1. 优先使用会话首次有效任务时的 Git 分支；钩子已提供首次分支时以其为准。
2. 首次没有可用分支时，使用首次任务的简洁摘要作为固定前缀。首次命名时前缀与右侧摘要可以相同。
3. 固定前缀在整个会话中保持不变；后续切换分支或更换任务都不改变它。不要把空首次分支替换为后续分支。

## 最新任务摘要

- 首次尚无符合规则的标题时设置标题；已有标题时，只有用户明确切换到明显不同的任务且右侧摘要需要改变，才更新标题。
- 闲聊、问候、感谢，以及同一任务的补充、纠正、确认、进度询问和相关追问均保留当前标题；无法确定是否切换任务时也保留当前标题。生成的完整标题与当前标题相同时，不调用标题工具。
- 中文请求优先使用简洁、明确的中文动宾短语；不要照搬整段请求、路径、附件元数据或提示词包装。
- 宿主提供可用的会话改名工具时传入真实的完整标题；没有时提供该标题供用户手动设置。不得传占位词、模板、变量名或说明文字。
- 用户明确要求保留标题、手动指定标题或已经手动更改标题时，尊重用户决定。

## 钩子边界

本技能定义通用规则，不自行监听事件。Codex 适配通过 `UserPromptSubmit` 提供判断上下文；其他宿主需单独适配其事件、会话存储和改名能力。钩子遇到无效输入、状态或 Git 信息不可用时应失败放行，不阻塞用户任务。Codex 约定见 `references/hook-contract.md`。
