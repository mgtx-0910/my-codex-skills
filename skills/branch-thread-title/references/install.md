# Codex 安装与检查

本说明和安装脚本仅适用于 Codex，不要在其他工具中运行以代替对应适配。

当用户明确要求启用本技能的自动标题时，使用随技能一起分发的 `scripts/install.py`。直接加载技能不会自行运行脚本或注册钩子。脚本需要 Python 3.10 或更高版本；Git 可用时获取首次分支，无分支时使用首次任务摘要。

1. 确定技能目录及 Python 解释器路径（Windows 可优先使用可用的 `python`、`py -3` 或 Codex 已配置的 Python；macOS/Linux 可使用 `python3`）。不要假设其他用户存在本机的绝对路径。
2. 执行 `<Python> <技能目录>/scripts/install.py install`。脚本使用 `CODEX_HOME`，未设置时使用用户主目录下的 `.codex`；复制随包钩子至该目录，并将事件配置追加至 `hooks.json`，保留其他事件和钩子。若已有配置则先备份。重复运行相同安装不会重复添加。
3. 检查脚本输出。遇到既有同类钩子、配置非法、路径不支持或脚本内容冲突时，不要覆盖或静默跳过；先检查冲突并向用户说明。检查安装状态可运行 `<Python> <技能目录>/scripts/install.py check`。脚本检查注册和文件是否一致，**不能确认 Codex 已信任或加载该钩子**。
4. 新钩子可能需要在 Codex 中审核和信任；由用户完成宿主要求的授权，不要修改或伪造信任记录。随后在新会话验证：首个任务生成固定前缀标题、同任务追问与闲聊不重复改名、切换到明显不同的任务后更新右侧。若未加载配置，再尝试重新打开会话或重启应用。

钩子使用模型判断任务是否变化，无法保证每次语义判断都正确。识别手动标题还依赖当前 Codex 的本地会话索引和记录，存储格式变化或记录不可用时可能失效。脚本注册依赖宿主支持 `UserPromptSubmit`、`hooks.json` 和附加上下文；标题更新依赖当前环境提供 `set_thread_title` 或等价标题工具。不要声称所有 Codex 版本或运行环境均支持。

如需停止自动标题，删除 `hooks.json` 中对应本技能脚本的 `UserPromptSubmit` 项，保留其他项。对既有手动修改过的文件，先检查内容；不要直接还原整个备份以免覆盖后续更改。
